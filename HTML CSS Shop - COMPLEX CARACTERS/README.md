# Complex Characters - HTML/CSS Shop

Static storefront project for a character-themed product catalog, built with plain HTML and CSS.

## Overview

This project demonstrates front-end fundamentals through a multi-page shopping interface, including product categories, product detail pages, and basic informational pages.

## Pages

- Home: [`index.html`](index.html)
- Product categories: [`product-categories.html`](product-categories.html)
- Product listings/details: [`men-tshirt.html`](men-tshirt.html), [`men-tshirt1-details.html`](men-tshirt1-details.html), [`wom-jack.html`](wom-jack.html), [`wom-jack1-details.html`](wom-jack1-details.html)
- Supporting pages: [`about-us.html`](about-us.html), [`contact.html`](contact.html), [`registration.html`](registration.html)

## Technologies

- [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML)
- [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS)

## Run

No build step is required. Open [`index.html`](index.html) in a browser.

## Notes

- Styling is centralized in [`style.css`](style.css).
- This is a static UI prototype (no backend or payment integration).
