# Untitled Luxury - HTML/CSS Shop

Static luxury-themed storefront project built with HTML and CSS, focused on clean visual presentation and straightforward navigation.

## Overview

The project includes landing, category, item detail, and informational pages to model a lightweight e-commerce browsing experience.

## Pages

- Home: [`index.html`](index.html)
- Categories and listings: [`categories.html`](categories.html), [`suits.html`](suits.html), [`villas.html`](villas.html)
- Detail pages: [`suit1.html`](suit1.html), [`villa1.html`](villa1.html)
- Supporting pages: [`aboutus.html`](aboutus.html), [`contact.html`](contact.html), [`registration.html`](registration.html)

## Technologies

- [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML)
- [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS)

## Run

No installation is required. Open [`index.html`](index.html) in a browser.

## Notes

- Main styling is defined in [`style.css`](style.css).
- This is a static front-end prototype without backend services.
